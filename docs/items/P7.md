## Ideas

- 2026-10-25: Normalise text to NFC before folding, the real fix for decomposed letters in every script; dropping combining marks in `fold.toml` suits only Latin-1 and Latin Extended-A. A normalisation crate needs `kx-licence-check` first (from P7).
- 2026-10-25: Give each small pack a coverage target instead of one raw byte cap, which favours one-byte scripts (Tamil covers 81.6%) (from P7).
- 2026-10-25: Small packs keep wordfreq's lower case (German nouns as `haus`); licence-checked Hunspell dictionaries for more languages would restore their capitals and filter them (from P7).
- 2026-10-26: Capitalise word chips at a sentence start (after a full stop or a new line), as phone keyboards do; today a new sentence costs one Shift tap (owner, from P7's final review).
- 2026-10-26: One Backspace right after a pick undoes the whole pick and puts back exactly what was typed; mis-taps are frequent for one-finger users (owner, from P7's final review).
- 2026-10-26: Serbian gets a seed when the layout source carries a script tag, so a Latin layout uses the `sh` pack and a Cyrillic one does not (from P7's final review).
