# P5 — Scroll pad

## Already built

- The three scroll routes; G6 scrolled Notepad, Chrome and Explorer ([move map, P5](../spike-move-map.md#p5-to-p12--one-feature-each)).

## Notes

- New in this phase: the two-speed pad, target tracking and its outline.
- The Word retest moved from P3 is dropped: the owner tests with Word nowhere, as its sign-in and subscription windows block every test (owner, 2026-10-16; roadmap G6).
- Checked in the manual test: the agent presses a key, drags off the keyboard and releases outside, then enters the keyboard normally from another window, and the owner confirms what they see; the pad must scroll that window, not the one where the drag ended. Result (2026-10-17): not run, as the check needs a drag by hand and a tool without uiAccess cannot send input to our windows; the entry watch's tests cover a capture lost off the keyboard.
- Checked in the manual test: a build without uiAccess (plain `cargo run`) against an elevated target, such as an admin Notepad; note whether the pad scrolls it by `ScrollPattern`, says "Nothing to scroll there", or lights and moves nothing. Result (2026-10-17), on the test build (`--features gate-input`, no uiAccess) rather than plain `cargo run`: the pad scrolled nothing in the admin Notepad, by wheel or by `ScrollPattern`, and no key, Right-click or Grab reached it either, as Windows blocks input from a program without uiAccess. Whether the pad stayed lit or showed a notice was not noted. The installed build types into it and scrolls it.

## Ideas

- 2026-10-17 (owner, manual test): aim where the pointer last rested before the keyboard, not at its last point outside it. A small window's path to the keyboard crosses the big window behind it, which the pad then picks; a pause of about a third of a second (a setting) in the pointer's kept history would mark the window meant. The owner kept the wheel-like rule for P5.
- 2026-10-17 (G6 run 1, deferred): an end tolerance in pixels, so Explorer's bottom (99.991 %) reads as the end at once instead of after the wheel trips and the steps judge it.
