## Ideas

- 2026-10-10: the Windows key shows the system's own mark, so the keyboard feels native on each system.
  - Today one theme token picks the drawing (`icons.toml` `win = "win-logo"`); it should come from each platform's adapter table instead.
  - On macOS the key is Command, drawn as ⌘ (Apple's keyboards print ⌘, not the Apple logo, which Apple restricts). On Linux it is Super; check Tux's licence and GNOME/KDE's own drawing before choosing.
- 2026-10-10: every rule of the keyboard core must hold on every system, not only Windows.
  - For example, a key that types nothing with Shift or `AltGr` shows empty (P3). Each system's layout reader must report "types nothing" the same way (macOS `UCKeyTranslate`, Linux xkbcommon).
