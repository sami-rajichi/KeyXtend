# F8 — Read aloud + translate

## Already built

- P10's Translate keycap opens the selection in the browser's translate page, after one consent (`docs/superpowers/specs/2026-11-07-selection-chips-design.md`).

## Notes

- **The translation box (owner, 2026-11-07, from P10):** the same Translate keycap shows the translation in a small box inside KeyXtend, from the detected language into the chosen one, as browser extensions do. A `[selection] translate_with` setting picks "browser page" or "on this PC".
- **Engine:** translate on the PC, as Firefox and Zen do ([Zen](https://docs.zen-browser.app/user-manual/translate)), with Mozilla's Bergamot models: about 24 MB per direction, Arabic both ways, MPL-2.0 ([mirror listing](https://huggingface.co/Freonius/jerome-translation-models)). Run `kx-licence-check` on the engine and models first; confirm sizes and licences from Mozilla's own files.
- The browser page stays as the other choice: P10's link builder (`Site::link` in `kx-mod-selection`) and `[selection] translate_chars` stay, and the site row's `link_max` in `sites.toml` (8000 bytes, provisional) takes the value G19's `translate-read` measures (from P10, 2026-11-08).
- Reuse P11's parts: the worker's native engine build, the model download with its SHA-256 check, and the idle stop. French and Arabic go through English when no direct pair exists.
- Not a private cloud address: extensions use Google's or Microsoft's unpublished endpoints, which a sold app must not rely on. A free official service needs an account and a key per user (Microsoft's free tier is 2 million characters a month, DeepL's 500,000).
