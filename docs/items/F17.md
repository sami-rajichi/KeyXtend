# F17 — Add your own voice model

## Already built

- Nothing yet. P11 offers only the ten models of `crates/kx-mod-voice/models.toml`, each checked by its size and SHA-256 before use (ADR-0043).

## Notes

- The engine, transcribe.cpp 0.4.1, knows 18 speech families: Whisper, Parakeet (Nemotron too), Canary, Canary-Qwen, Cohere Transcribe, Qwen3-ASR, Voxtral and Voxtral Realtime, Moonshine and Moonshine Streaming, SenseVoice, FunASR Nano, GigaAM, Granite, Granite NAR, Granite 5 CTC, MedASR and MOSS (2026-11-17, its `src/arch` folder).
- It reads only files converted to its own GGUF layout, plus older whisper.cpp `.bin` files; a GGUF made for another engine does not load.
- A free field (a Hugging Face id) would lose what each table row gives: the SHA-256 check, the measured memory needs behind the fit check, the licence check a sold app needs, and the measured word errors behind the orders. A model's languages can still be read from its file.
- The engine is C++ and parses each file: an outside file is untrusted input, so it would load only in the sandboxed worker job, as today.
