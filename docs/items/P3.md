- **Manual check** (G1 in Notepad): Notepad drops a few characters right after punctuation in fast G1 bursts (likely its spell-check).
- **Handled** (`assets/`, with licences, compiled in; ADR-0016): Fonts and icons are staged from outside git; decide with `kx-licence-check` whether they live in the repo or are fetched by hash.
- **Handled** (the QPC clock): `kx-target-window` switches from `spike_core::clock::now_us` to the product QPC clock in `kx-platform-windows` and drops `spike-core`. `kx-gates` keeps `spike-core` for far more than the clock (`inject`, `hold`, `window`, `config`, `uia` and others) until its gates move, so root `cargo fmt --all` still reaches `spike/core` until then.
- **Handled** (`apps/keyxtend` `run.rs`): The Windows adapter builds `AppDirs` (`%LocalAppData%\KeyXtend` through the known-folder API), and the app picks the data folder with `AppDirs::data_dir()`.
- **Handled** (`kx-ui` `i18n/*.ftl`; typed notice arguments, with `list.join`): The six P2 notice keys (the `kx_module_api::keys` constants) need EN/FR/AR texts. The `keys` argument of `notice.settings-reset` should become a list, so each language joins and labels it (Arabic uses "، ").
- **Handled** (`list.more` in each language): `notice.settings-reset` names at most 10 keys (`MAX_NAMED_KEYS`), none over `MAX_KEY_CHARS` characters; its optional `more` argument counts the rest, so each language needs an "and N more" text.
- **Handled** (`SettingsHandle`, `set_all`): Modules need a live settings handle for values they write themselves (size, position); for now a settings change restarts the module.
- **Handled** (`apps/keyxtend` `log.rs`, `run.rs`): The app installs the redacted log subscriber (`log_level`, `log_max_mb`) and calls the kernel's boot and stop.
- **Handled** (`apps/keyxtend` `quiet.rs`): The app installs a quiet panic hook that logs only the location, never the payload, because caught module panics still print through the default hook.
- **Handled** (`apps/keyxtend` `log.rs`): `LogFile::open` returns an error when the previous log cannot be replaced; the app then runs without a file log and says so once.
- **Handled** (`Kernel::load`, then `start`): The kernel cannot yet give `[kernel] log_level` and `log_max_mb` before modules start; split `boot` into load and start, or add a settings getter, so the log opens first.
- **Handled** (`Event::CAPABILITY`; P7 and P8 notes): Bus events have no capability gate: any module can subscribe to, intercept or publish any event, even future typed-text events. Decide it here, for example with an optional `Event::CAPABILITY` that `ModuleCx::subscribe` and `intercept` check.
- **Handled** (`notice.settings-locked`): A settings file that cannot be opened for a reason other than "not found" (for example another program's lock) counts as damaged, so a short lock could set a healthy file aside. Treat such errors as "try again": run on defaults in memory and do not save.
- **Handled** (`kx-review` check 4): The log hides fields by snake_case name parts; the app's own fields must follow that style (`typed_text`, not `typedText` or `passwords`).
- **Handled** (`kx-review` check 4): The log hides fields by name only: text formatted into the message, and names like `key`, `input` or `content`, print in clear. Keep typed text in `Redacted<T>`, and add a review or lint check for `tracing` calls in input modules.
- **Handled** (`set_setting` tries a failed module again): After the Settings window changes a value that made a module fail, restart that module; today `set_setting` restarts only running modules, so the user must also press Try again.
- **Manual check** (G8's bus row, `[g8] bus_share`): The bus copies its handler list on every publish. Measure it in the G8 budgets and switch to a copy-on-write list if it shows.
- **Manual check** (G8's cold start): `Kernel::disabled()` reads the kernel section on every call; that is fine for about 20 modules, but cache it if start-up time shows it.
- **Handled** (the gates aim by UI Automation id and box): G2 and G4 aim with a key map older than the keyboard's top bar, so their clicks land one row high (P2 check: 5 of 96 characters matched). Read the key rectangles from the face, or add the bar, before the gates move to the product keyboard.
- **Handled** (the product ends through `--quit` or the tray's Quit; `WM_CLOSE` on the keyboard is not a quit path): `kx-gates close qt` closes the keyboard window but leaves its process running with a hidden window; the product keyboard must quit when its last window closes.
- **Handled** (`ci.yml` Windows job): Add the Qt build job to Windows CI (owner's decision, 2026-09-29).
