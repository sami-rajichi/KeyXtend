## Notes

- Native Adaptive keeps its own blue; following the system accent is a setting, off by default (owner's decision).
- To fix (ADR-0013): ClearType colour fringes on thin text, no hover outline in high contrast, `Icon.qml` using Qt's internal `QtQuick.Controls.impl`, and re-measuring the resize time (165 → 43 ms in a debug build).
- Also open: dead-key edge cases; split `sysui::contrast_palette` when the tokens grow.
- Word blocked G1 and G6 with its sign-in and subscription dialogs; retest inside a Word window that is already signed in.
- Notepad drops a few characters right after punctuation in fast G1 bursts (likely its spell-check).
- Fonts and icons are staged from outside git; decide with `kx-licence-check` whether they live in the repo or are fetched by hash.
- The test certificate and the Program Files test install are kept for this phase's uiAccess tests. The certificate expires on 2026-12-26; the owner decides when to remove it.
- `kx-target-window` switches from `spike_core::clock::now_us` to the product QPC clock in `kx-platform-windows` and drops `spike-core`. `kx-gates` keeps `spike-core` for far more than the clock (`inject`, `hold`, `window`, `config`, `uia` and others) until its gates move, so root `cargo fmt --all` still reaches `spike/core` until then.
- The Windows adapter builds `AppDirs` (`%LocalAppData%\KeyXtend` through the known-folder API), and the app picks the data folder with `AppDirs::data_dir()`.
- The six P2 notice keys (the `kx_module_api::keys` constants) need EN/FR/AR texts. The `keys` argument of `notice.settings-reset` should become a list, so each language joins and labels it (Arabic uses "، ").
- `notice.settings-reset` names at most 10 keys (`MAX_NAMED_KEYS`), none over `MAX_KEY_CHARS` characters; its optional `more` argument counts the rest, so each language needs an "and N more" text.
- Modules need a live settings handle for values they write themselves (size, position); for now a settings change restarts the module.
- The app installs the redacted log subscriber (`log_level`, `log_max_mb`) and calls the kernel's boot and stop.
- The app installs a quiet panic hook that logs only the location, never the payload, because caught module panics still print through the default hook.
- `LogFile::open` returns an error when the previous log cannot be replaced; the app then runs without a file log and says so once.
- The kernel cannot yet give `[kernel] log_level` and `log_max_mb` before modules start; split `boot` into load and start, or add a settings getter, so the log opens first.
- Bus events have no capability gate: any module can subscribe to, intercept or publish any event, even future typed-text events. Decide it here, for example with an optional `Event::CAPABILITY` that `ModuleCx::subscribe` and `intercept` check.
- A settings file that cannot be opened for a reason other than "not found" (for example another program's lock) counts as damaged, so a short lock could set a healthy file aside. Treat such errors as "try again": run on defaults in memory and do not save.
- A module that boot stopped quietly (its provider is switched off and blocked) stays stopped if that provider is later switched on and fails; only the provider shows a notice. Show waiting modules in the Settings window.
- The log hides fields by snake_case name parts; the app's own fields must follow that style (`typed_text`, not `typedText` or `passwords`).
- The log hides fields by name only: text formatted into the message, and names like `key`, `input` or `content`, print in clear. Keep typed text in `Redacted<T>`, and add a review or lint check for `tracing` calls in input modules.
- After the Settings window changes a value that made a module fail, restart that module; today `set_setting` restarts only running modules, so the user must also press Try again.
- The bus copies its handler list on every publish. Measure it in the G8 budgets and switch to a copy-on-write list if it shows.
- `Kernel::disabled()` reads the kernel section on every call; that is fine for about 20 modules, but cache it if start-up time shows it.
- G2 and G4 aim with a key map older than the keyboard's top bar, so their clicks land one row high (P2 check: 5 of 96 characters matched). Read the key rectangles from the face, or add the bar, before the gates move to the product keyboard.
- `kx-gates close qt` closes the keyboard window but leaves its process running with a hidden window; the product keyboard must quit when its last window closes.
- Add the Qt build job to Windows CI (owner's decision, 2026-09-29).
