# P10 — Selection helper

## Already built

- The Copy pill: G19 placed it at most 1 px off, kept focus and copied ([move map, P5 to P12](../spike-move-map.md#p5-to-p12--one-feature-each)).

## Notes

- **Handled in P10 (2026-11-08):** the spike's `qt-kb/qmltest/tst_extras.qml` failed one pill case offscreen ("the shadow fades with it"), as kx-ui's `Soft.qml` needs the shadow plugin. The case moved into kx-ui's `tst_selchips_app.qml`, which loads it (`kx-test-icons`) (from P4's review, 2026-10-14).
- **Handled in P10:** a label longer than "Copy" was placed as if `pill_px[0]` wide. Each keycap is now as wide as its legend, and the hub places the strip from the size QML measured (`sel_at`).
- **Handled in P10:** Word was not tested in G19 (its sign-in dialog blocked it). G19 now never targets Word.
- **Handled in P10:** Grab (P4) ends a text selection with one click (spec §5.1, from P4, 2026-10-13). The module follows Grab's state (`AssistChanged`) rather than `AssistNote`, which needs `KeyboardUi`: no look while Grab carries, and after the drop the next release or the app's own selection event looks.
- **Handled in P10:** never test with Word (owner, 2026-10-16, from P5). G19 runs in Notepad, Chrome, Windows Terminal and the console.
