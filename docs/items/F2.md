## Notes

- P11 left voice commands out (P11 design, "Non-goals in part 1").
- Since P11 one engine, transcribe.cpp, runs every local speech model, Whisper among them (ADR-0043).
- The keyboard stays the only typist (ADR-0042 decision 7), so a command that types or presses keys asks the keyboard, as a dictated text does.
- Only Nemotron writes while the user speaks, its text final 0.1 to 0.3 s after the last sound, which a command list may want (P11 trial, `docs/items/P11.md`).
