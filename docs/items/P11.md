## Notes

- Weak mode in P1's G22 timings was probably not throttled: the job's CPU rate was a share of the whole PC, so 30 % never capped two cores on a 16-thread PC (found in P3 Task 24). Re-time G22 in weak mode once `weak.rs` caps each core.
- New in this phase: the model download with a SHA-256 check, the benchmark button, the forced language and the transcript history.
- The local base model runs at 0.14× real time but suits English only; French and Arabic are still to be tested with larger models and the cloud engines.
- Users pick a local model, their own API key or a provider; a model loads once and stays loaded.
- A worker note shown while recording hides the red recording dot.
