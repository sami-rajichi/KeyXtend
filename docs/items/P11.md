- Both large Whisper models add an invented Arabic credit line after the silence before Stop, and Cohere's general model stops a long Arabic clip early; cutting that silence fixes both. A crude loudness cut costs other models a word or two, so use a real voice detector with padding.
- Cohere's general model writes Arabic without hamza and with ه for ة; its Arabic model spells correctly.
- Only Nemotron can write while the user speaks: its text is final 0.1 to 0.3 s after the last sound. This `transcribe-cpp` has no short-clip cut for Whisper, so an 8 s clip costs Turbo a full 30 s window.
- Nemotron names languages by region (`en-US`, `fr-FR`, `ar-AR`), so the models table maps the keyboard's language to each model's own code.
- Graphics card, 2026-11-10 (same test built with Vulkan, on an 8 GB laptop card): every model answers an 8 s clip in 0.1 to 0.4 s and a 30 s clip in 0.4 to 1.3 s, with the same mistakes as on the processor. Parakeet takes 0.1 s and 0.4 s, Cohere Arabic 0.25 s and 0.7 s, Whisper Large v3 0.35 s and 1.3 s.
- On the card a model takes 0.3 to 2.4 GB of card memory, loads in 0.6 to 5.7 s, and holds more normal memory than on the processor. The laptop's built-in graphics chip is still 3 to 4 times faster than the processor.
- The first use of a model family on a card compiles its programs once (23 to 36 s here); the driver keeps them, so later starts take under a second. Do it in the background when the card is switched on.
- The engine lists each device with its total and free memory, which serves the fit check. The static Vulkan build adds 45 MB and needs the SDK's `vulkan-1.lib` on the link path; a statically linked worker cannot start on a PC without Vulkan, so ship the card part as a loadable module (`dynamic-backends`).

- The engine also opens an older whisper.cpp file: `ggml-small-q5_1.bin` loaded and read all six clips (2026-11-10).
- `transcribe-cpp`'s `dynamic-backends` feature also builds the processor variants on x86 (`GGML_CPU_ALL_VARIANTS`) and picks one at start. The plain build pins a safe processor floor on macOS only, so the trial's Windows build must not ship as it is.
- The mock-up names the sizes `shape.toml` lacks as `--voice-*` CSS values (bar width 500/640, wave bars 4/3/3, switch 40×22, stepper box 92, compare column 84); task 24 adds them as `[voice]` tokens.
- Sandbox proofs, 2026-11-14 (`kx-gates boxed`, the worker's own token and job): the microphone records at 48 kHz stereo under a 256 MB cap. The engine lists both graphics chips and the processor, and Parakeet runs on the RTX 4060 with the same words wrong as on the processor (31 s of French in 0.52 s against 3.15 s; load 5.4 s against 0.5 s).
- The engine reads four environment variables: `GGML_BACKEND_PATH` loads an outside library, `TRANSCRIBE_DUMP_DIR` writes working data to disk, `TRANSCRIBE_BACKENDS` and `GGML_DISABLE_VULKAN` narrow the devices (2026-11-14). The host must start the worker with every `GGML_*` and `TRANSCRIBE_*` variable removed, and load the parts with `init_backends(dir)` from the worker's folder.
- The engine's voice detector is Silero VAD through `Model::vad_session`, from a GGUF or whisper.cpp `.bin` file; its options are Silero's own (`threshold`, `min_speech_ms` and the rest). The file ships in `assets/voice/`.
- Build proofs, 2026-11-14 (`dynamic-backends` + Vulkan): the loadable parts pack to 18.7 MB at the budget's deflate level, the card part alone 14.2 MB (45 MB unpacked), so the stage lands near 63 MB of 80. Only `ggml-vulkan.dll` imports `vulkan-1.dll`; every part needs the same C++ runtime Qt already needs.
- With the card part removed or cut short, the engine starts on the processor and types the same words; with only `ggml-cpu-x64.dll` it runs 4 to 5 times slower (31 s of French in 24.6 s), same words. With no processor part, start fails with a clean error, so the stage check must require one.
- Detector, 2026-11-14, ten models on the six clips (words wrong in total): no cut 267, pad 200 ms 242, pad 300 ms 230, pad 500 ms 269, threshold 0.35 with pad 300 ms 229. Defaults: threshold 0.5, pad 300 ms, min silence 100 ms, min speech 250 ms; the cut fixes Cohere general's early stop on long Arabic (22 to 2) and Whisper's invented Arabic line, and leaves the default models as they were (Parakeet 7 to 8, Cohere Arabic 0).

## Ideas

- 2026-09-29: Voice settings choose cloud or local. Cloud: pick the provider, then enter your API key, which is stored encrypted, never in the settings file. Local: pick from a suggested model list; models download into KeyXtend's own data folder.
- 2026-11-09: While recording, the bar shows a wave that follows the real voice level, as Wispr Flow and ChatGPT's mic do: it rises with speech and flattens on a breath or a pause. The text shows after Stop only, by the mic key or the bar's stop button.
- 2026-11-09: Models live in one visible folder the user picks, never a hidden cache on the system drive. A model file the user already has is reused, not downloaded again.
- 2026-11-09: A model whose minimum needs the PC does not meet is switched off, with the reason shown. With no usable model, only cloud is offered.
- 2026-11-09: The model list offers Whisper Large v3 beside Turbo: the owner finds Large v3 more capable and Turbo faster, and doubts Turbo's Arabic. Check both with real Arabic and French speech.
- 2026-11-09: P11 counts usage (time recorded and dictations per engine, never content), so P13's dashboard has data.
- 2026-11-09: Before choosing cloud services, the owner wants each one compared: free tier, monthly cost, whether it trains on the user's voice, and how its key is stored.
- 2026-11-10: The Voice key starts listening at once, in the keyboard's language, with no Start button. The bar keeps its gear in every state, the result too, and the tray menu gets a Voice typing row.
- 2026-11-10: Any model may serve any language it knows; the panel only notes which model is best for the language in front (for now Cohere's for Arabic). The language is always set, never guessed.
- 2026-11-10: Engines, models and cloud services are plug-in parts: adding, removing or updating one touches a table or one small adapter, never the feature's code.
- 2026-11-10: Offer as many cloud services as fit, each with its free use and cost: Groq, OpenAI, Mistral, Azure with MAI, ElevenLabs and Google's model, plus OpenRouter, NVIDIA's API and HeyGen if they transcribe.
- 2026-11-10: The model test (read a set text, then compare accuracy, speed and memory per model) stays a tool the owner can run again when a model changes. A model weak for the owner stays listed, as it may suit someone else; the owner picks the default after the tests.
- 2026-11-10: Test Arabic as standard Arabic, not as one dialect.
- 2026-11-10, after the trial: one engine runner, `transcribe.cpp`, serves every model family.
- 2026-11-10: Defaults go by keyboard language: Parakeet v3 for French and English, Cohere Transcribe Arabic for Arabic. Every other model stays selectable.
- 2026-11-10: A model leaves memory some minutes after the last dictation (a setting). Each dictation's audio and working memory are freed at once, so nothing leaks.
- 2026-11-10: The user chooses the processor or the graphics card, and not through CUDA alone (Vulkan, Metal on a Mac). Before loading on a card, check its free memory against the model's need; fall back to the processor rather than freeze.
- 2026-11-10: No word-by-word writing: a model hears the whole recording, then writes. The small Nemotron stays listed but is never a default.
- 2026-11-10: P11 is delivered in two parts. Part 1 is all that runs on the PC: the bar, the local models, the graphics card choice, the Voice panel, Compare models and history. Part 2 is the cloud services, in its own session right after.
- 2026-11-10: The key and its screen-reader name both say Dictation · Dictée · إملاء.
- 2026-11-10: Compare models is a tool in the Voice panel: it shows a set text, records once, runs each installed model, and lists mistakes, waiting time and memory. It replaces the speed-only benchmark button.
- 2026-11-10: Cloud (part 2): the shared OpenAI-style connection (Groq, OpenAI, Mistral, OpenRouter, Together, Lemonfox, OVHcloud), Azure with MAI, DeepInfra, and direct connections to ElevenLabs and Google Gemini, since their plans or free tier carry an allowance that OpenRouter cannot use.
- 2026-11-10: Users install nothing for the graphics card: its drivers already bring Vulkan. The Vulkan SDK is a build tool only.
- 2026-11-10: After Stop the text is typed at once; the bar keeps Copy, Undo insert and Close. "Stop after silence" is a setting, off to start.
- 2026-11-10: History keeps the last 50 texts, encrypted, each with its date and time. It is on to start, with a switch to turn it off and Delete all.
- 2026-11-10: A second switch, off to start, also keeps each dictation's recording with its text and date, so the owner can gather their own voice data for later speech work.
- 2026-11-10: Both parts are designed now, as two documents; part 1 is built first.
- 2026-11-10: A recording stays in memory until its bar closes, so Try again works without speaking again; then it is wiped.
- 2026-11-10: Cloud (part 2): nothing is sent before Stop, so Cancel sends nothing.
- 2026-11-10: Dictation works in every keyboard language a model knows; languages other than English, French and Arabic are marked untested.
- 2026-11-10: Both designs are approved. Both plans are written before any building, and building starts only after the owner has checked them.
- 2026-11-10: Both plans are approved, after an independent check. Part 1 is built first, on Opus, when the owner starts it; part 2 follows once part 1 is merged.
- 2026-11-14: The full mock-up (`design/voice-bar.html` and `voice-bar.js`) is approved: Stop stays dimmed while transcribing, Stop is dark, and the panel opens above the bar.
