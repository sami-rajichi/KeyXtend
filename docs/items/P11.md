## Ideas

- 2026-09-29: Voice settings choose cloud or local. Cloud: pick the provider, then enter your API key, which is stored encrypted, never in the settings file. Local: pick from a suggested model list; models download into KeyXtend's own data folder.
- 2026-11-09: While recording, the bar shows a wave that follows the real voice level, as Wispr Flow and ChatGPT's mic do: it rises with speech and flattens on a breath or a pause. The text shows after Stop only, by the mic key or the bar's stop button. Built (2026-11-16).
- 2026-11-09: Models live in one visible folder the user picks, never a hidden cache on the system drive. A model file the user already has is reused, not downloaded again. Built (2026-11-16).
- 2026-11-09: A model whose minimum needs the PC does not meet is switched off, with the reason shown. With no usable model, only cloud is offered. Built for local models (2026-11-16); the cloud is part 2.
- 2026-11-09: The model list offers Whisper Large v3 beside Turbo: the owner finds Large v3 more capable and Turbo faster, and doubts Turbo's Arabic. Check both with real Arabic and French speech. Built (2026-11-16).
- 2026-11-09: P11 counts usage (time recorded and dictations per engine, never content), so P13's dashboard has data. Built (2026-11-16).
- 2026-11-09: Before choosing cloud services, the owner wants each one compared: free tier, monthly cost, whether it trains on the user's voice, and how its key is stored.
- 2026-11-10: The Voice key starts listening at once, in the keyboard's language, with no Start button. The bar keeps its gear in every state, the result too, and the tray menu gets a Voice typing row. Built (2026-11-16).
- 2026-11-10: Any model may serve any language it knows; the panel only notes which model is best for the language in front (for now Cohere's for Arabic). The language is always set, never guessed. Built (2026-11-16).
- 2026-11-10: Engines, models and cloud services are plug-in parts: adding, removing or updating one touches a table or one small adapter, never the feature's code. Built for local models (2026-11-16); the cloud is part 2.
- 2026-11-10: Offer as many cloud services as fit, each with its free use and cost: Groq, OpenAI, Mistral, Azure with MAI, ElevenLabs and Google's model, plus OpenRouter, NVIDIA's API and HeyGen if they transcribe.
- 2026-11-10: The model test (read a set text, then compare accuracy, speed and memory per model) stays a tool the owner can run again when a model changes. A model weak for the owner stays listed, as it may suit someone else; the owner picks the default after the tests. Built (2026-11-16).
- 2026-11-10: Test Arabic as standard Arabic, not as one dialect. Built (2026-11-16).
- 2026-11-10, after the trial: one engine runner, `transcribe.cpp`, serves every model family. Built (2026-11-16).
- 2026-11-10: Defaults go by keyboard language: Parakeet v3 for French and English, Cohere Transcribe Arabic for Arabic. Every other model stays selectable. Built (2026-11-16).
- 2026-11-10: A model leaves memory some minutes after the last dictation (a setting). Each dictation's audio and working memory are freed at once, so nothing leaks. Built (2026-11-16).
- 2026-11-10: The user chooses the processor or the graphics card, and not through CUDA alone (Vulkan, Metal on a Mac). Before loading on a card, check its free memory against the model's need; fall back to the processor rather than freeze. Built on Windows with Vulkan (2026-11-16); Metal comes with P15.
- 2026-11-10: No word-by-word writing: a model hears the whole recording, then writes. The small Nemotron stays listed but is never a default. Built (2026-11-16).
- 2026-11-10: P11 is delivered in two parts. Part 1 is all that runs on the PC: the bar, the local models, the graphics card choice, the Voice panel, Compare models and history. Part 2 is the cloud services, in its own session right after. Part 1 built (2026-11-16).
- 2026-11-10: The key and its screen-reader name both say Dictation · Dictée · إملاء. Built (2026-11-16).
- 2026-11-10: Compare models is a tool in the Voice panel: it shows a set text, records once, runs each installed model, and lists mistakes, waiting time and memory. It replaces the speed-only benchmark button. Built (2026-11-16).
