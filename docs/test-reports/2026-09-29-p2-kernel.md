## Notes
1. G2 stopped after 64 clicks, when a key pop-up covered 20 keys. Only 5 of the 96 characters matched their key: the gate's key map predates the keyboard's top bar (G2 ran on 2026-09-27, the full keyboard came on 2026-09-28), so clicks land one row high. This is P1 debt, noted for P3.
2. The last good copy is the file as it was before the latest save, so the value came back as 1200, not the 1300 held in the damaged file (ADR-0015).
3. Clicks from an unsigned `kx-gates` never reach the uiAccess keyboard, because Windows drops them. The Qt gates need the signed tool from Program Files, as the P1 harness did.
4. `kx-gates close qt` closes the keyboard window, but its process keeps running with one hidden window. Only an admin prompt could end it.
