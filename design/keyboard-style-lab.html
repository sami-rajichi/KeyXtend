Reading · on-screen keyboards compared

Why build a new on-screen keyboard?

Windows' On-Screen Keyboard has click, hover and scan modes, but users report keys that render tiny, and it has no themes. The Windows 11 touch keyboard has themes and a clipboard tab, but it is built for touch screens.

macOS already solves part of the mouse problem: its Dwell actions include right click, drag and drop, and a scroll menu, and the countdown is a circle around the pointer. OptiKey's Look to Scroll keeps scrolling by itself.

Arabic is the gap. Windows Voice Access and voice typing do not list Arabic. Whisper large-v3 reaches about 14.6% word errors on Arabic in the FLEURS test, against 4.1% for English and 5.8% for French.

Connecting…

Themes updated

  • Three themes: Native Adaptive (the default, light), ET66, Modern Dolch.
  • Each one has a soft dark version: dark grey instead of black and off-white text, following Material Design's dark theme guidance and GitHub's Dark Dimmed theme.
  • Light and dark switch from the keyboard itself (sun and moon button) or follow the system.

Typing

  • Detects every input language installed on the system. Today: English (QWERTY), French (AZERTY), Arabic (101).
  • Keys show only the active language. Language key design still open: carousel, cycle or list.
  • Shift, Ctrl, Alt, Win work like osk.exe: one click holds the key, the next click releases it, and it also releases after the next normal key. A setting keeps it held instead.
  • Every system shortcut works (Ctrl+A, Win+V, Alt+Tab…). Light word prediction, emails included.

Window and panels

  • Floating only, always on top of every window, never takes the focus.
  • Small by default and resizable. Every panel grows and shrinks with the keyboard.
  • No panel ever needs scrolling: lists show five items at a time, with big ▲ ▼ buttons, and the keyboard's arrows, Enter, Space and Esc work inside them.
  • Nav block removed; PrtScn becomes Snip; Help becomes Settings.

Right-click key updated

  • An on/off key. Normal left clicks keep working while it is on.
  • How the real app does it: it holds your press back for a moment. Release before 1.5 s: a normal click is sent at once. Move: a normal drag. Hold still 1.5 s: a right-click instead, and the left click is never sent.
  • So nothing gets clicked by accident, and selected text stays selected for the menu.

Grab key

  • For drag and drop and text selection. Turning it on switches Right-click off.
  • Hold 1.5 s: grabbed. Move freely. One click drops or ends the selection. Grab switches off and Right-click comes back.

Scroll pad updated

  • Tap a direction: slow. Tap it again: faster. Third tap: stop. The centre Stop button works too.
  • Scrolls whatever is under the pointer, including long text fields. While the pointer is on the keyboard, it keeps scrolling the last thing you pointed at, which is outlined.

Feedback

  • Wave ring into the pointer, burst, mode badge beside the pointer, soft bubble pop, soft key ticks. Each can be switched off.

Voice typing

  • Mic key: click to start, click to stop; pauses never cut you off.
  • Own start and stop sounds; live wave; caption bar at the bottom centre, never over the keyboard, with Copy and Undo.
  • Forced language setting (Auto, English, French, Arabic). Its own module.

AI at zero cost new

  • Whisper on your PC by default (free, MIT licence). Cloud only if you add your own free key.
  • Word prediction without heavy AI: word lists plus what you type, kept on your PC.
  • Details in the Tech choice tab.

Clipboard history updated

  • One vertical list, newest first. Shows the last five, then ▲ ▼ for older pages.
  • Previews, file names, source and time. Filters: text, images, files, media.
  • ↑ ↓ move, Enter pastes, Space ticks several, then Paste together.
  • Kept 1 week by default; video and audio 1 day; big files kept as references.

Quick-fill vault updated

  • Three tabs: Emails (with one-click domains), Passwords (locked until you unlock), Names.
  • Five rows per page, same keys as the clipboard. Fill the username or the password separately.
  • One encrypted file on your PC; export only when you ask.

Snip tool updated

  • Smaller toolbars, icons first, labels only when the keyboard is large.
  • Region, window, full screen, scrolling page, timer. Click, move, click.
  • Arrow, box, text, highlighter, pen, steps, crop, undo; copy text (OCR), copy, save, pin.

Selection helper

  • Whenever text is selected anywhere, a small Copy button appears next to it (like PopClip, SnipDo).

Power key

  • Opens the system's own power dialog.

Lego modules

  • Micro-kernel where every feature is a plugin, inspired by DeepSeek Harness.
  • One package per feature, with its own tests and permissions; built one by one, each fully tested before the next.

Open source on GitHub new

  • Anyone can download it, so every dependency's licence must fit, and releases must be signed and verifiable.
  • Code lives on your E: drive; I write the code, you are the product owner.

Security first

  • Least privilege per module; encrypted vault; sensitive clipboard entries skipped; nothing leaves the PC unless you choose a cloud engine.

The short version. The keyboard window is written in Rust with Slint, all the logic lives in plain Rust modules that do not depend on the UI, and every AI feature runs free and on your PC by default. Checked on 26 September 2026; items marked unverified still need a test on a real PC.

Framework Leading

Rust + Slint 1.18 for the keyboard window. To stay above the Start menu and type into admin windows, Windows requires the "uiAccess" flag. Microsoft's WebView2, which Tauri and Electron-style apps rely on, fails with uiAccess (issue 4884, closed "not planned"). Slint draws natively, so it avoids that.

Checked against Slint's own code and bug tracker: nothing blocks Windows. About 20 MB of memory, built-in screen-reader support and a tray icon. Four known traps, each with a fix:

  • The window library can quietly remove "never take focus". Fix: we guard the window and put it back.
  • Editing Arabic inside our own text boxes has a cursor bug. Typing Arabic into other apps and showing Arabic are fine. Fix: our settings use buttons, not text boxes.
  • See-through windows have drawing bugs. Fix: the ring around the pointer is drawn directly by Windows.
  • macOS and GNOME on Linux need extra work later. GNOME's Wayland session allows no always-on-top keyboard, for any app.

Fallback: Qt 6. Nobody has tested Slint with uiAccess yet, so that is test G3 in week one.

Week-one proof, pass or fail

  • Types into Notepad, Word, Chrome and Terminal without losing a character, in EN, FR and AR.
  • The signed build stays above the Start menu and types into an admin window.
  • Never steals the focus; Arabic letters join correctly.
  • Hold-to-right-click works through the mouse hook without delaying normal clicks.
  • Measure install size, memory and start time.

If Slint fails a gate, only the window layer changes. The modules stay.

Voice, free

  • On your PC: Whisper through whisper.cpp (MIT). Turbo model 574 MB, or "small" 190 MB for older PCs. Downloaded when you first turn voice on, not bundled.
  • Optional cloud, your own free key: Groq allows 8 hours of audio a day for free. Azure's free tier gives 5 hours a month and lists 18 Arabic dialects, including Moroccan, Algerian and Tunisian.
  • Gemini's free tier may use your audio for training, so it would only be offered with a clear warning.
  • Rejected: NVIDIA Parakeet (no Arabic); Moonshine Arabic (licence limits).

Prediction, OCR, camera

  • Word prediction: our own small engine, seeded from the wordfreq word lists (free to use with credit), learning from what you type, stored on your PC.
  • Copy text from a snip: Windows' built-in OCR, then Tesseract (Apache-2.0: Arabic, French, English), then PaddleOCR for hard Arabic.
  • Camera control (later): webcam and face-tracking through open ONNX models. Google's Project Gameface was archived in September 2025, and the MediaPipe runtime sends usage metrics to Google, so we avoid both.

Licence

  • Recommended: the app under GPL-3.0-or-later. Slint is free for GPLv3 projects, GPL meets the free signing service's rule, and every copy stays open source, as with OptiKey.
  • Also allowed by Slint: our code under MIT/Apache, with the finished app under GPLv3. Others could then reuse our code in closed products. You choose.
  • Reusable parts (prediction engine, voice wrapper): MIT or Apache-2.0.
  • Fonts (OFL) and icons (ISC) ship with their licence files; word lists (CC-BY-SA) stay separate files with credit.

Signing and safe releases

  • On your PC: a self-signed test certificate plus install in Program Files. That is enough for uiAccess while developing.
  • Public releases: apply to the SignPath Foundation, which signs free for open-source projects built on GitHub. Fallbacks: a Certum open-source certificate (about €69), or the Microsoft Store (unverified whether it allows uiAccess).
  • Every release: licence and security checks on all dependencies, a list of every component included, GitHub build attestations, checksums.
  • Windows SmartScreen still warns about any new app until it has enough downloads.

Architecture preview

  • A small trusted core. Windows only lets a window sit above the Start menu when its own program holds uiAccess, so the keyboard program itself is the signed one. It keeps only the keys, the mouse helpers and sending input, and it never goes online.
  • Helpers with normal rights do everything that touches outside data: voice and the internet, OCR, clipboard images and files. A bug in a helper cannot reach admin windows.
  • Micro-kernel. Each feature is its own module and declares what it needs and what it may do. Modules never touch the OS directly.
  • The full design is the next thing we discuss.

macOS and Linux

  • macOS: a non-activating panel window. Without a paid Apple account ($99 a year), users must allow the app once in Privacy & Security.
  • Linux: X11 works like Windows. On Wayland, typing goes through the system's Remote Desktop permission, which asks the user once. GNOME does not allow global mouse hooks.
